# Icon sources

- `staggered-hex.svg` is the current app icon source.
- `master.png` is the 1024px render of `staggered-hex.svg`. Regenerate the icon set from it:

  ```sh
  pnpm tauri icon src-tauri/icons/concepts/master.png
  ```

- `gamut-lockup.png`, `monogram.svg`, `organic.svg`, `organic-wordmark.svg`, and `technical.svg` are earlier concepts. They are not the current icon.
